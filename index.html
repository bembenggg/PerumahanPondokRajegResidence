NOTIFIKASI DARURAT

Notifikasi Tidak Masuk?

Sebagian HP (terutama Xiaomi/Redmi/POCO, Oppo, Vivo) suka mematikan notifikasi aplikasi di latar belakang untuk hemat baterai. Tekan tombol sesuai merk HP Anda untuk membuka pengaturan yang tepat (1 kali saja):

Xiaomi / Redmi / POCO (MIUI/HyperOS)

Aktifkan "Autostart" untuk Chrome.

bolt Buka Pengaturan Autostart
Xiaomi / Redmi / POCO — Battery Saver

Ubah battery saver Chrome jadi "No restrictions".

battery_charging_full Buka Pengaturan Baterai
Oppo / Realme (ColorOS)

Aktifkan Chrome di daftar "Startup Manager".

bolt Buka Startup Manager
Vivo (Funtouch OS)

Tambahkan Chrome ke daftar "Autostart Whitelist".

bolt Buka Pengaturan Vivo
Tombol di atas tidak berfungsi?

Buka manual: Settings HP → Apps/Aplikasi → cari "Chrome" → Battery/Baterai → pilih "No restrictions" / "Tanpa batasan". Lalu cari juga menu terpisah bernama "Autostart" di Settings atau di app Security/Keamanan bawaan HP, aktifkan untuk Chrome.

notifications_off
Amankan Notifikasi Darurat HP Anda terdeteksi sering memblokir notifikasi. Ketuk untuk perbaiki.
